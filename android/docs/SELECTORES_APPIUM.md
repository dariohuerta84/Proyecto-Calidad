# Selectores para Appium (testTag → resource-id)

La app activa `testTagsAsResourceId` en la raíz y en cada diálogo, así que cada `testTag` es un **resource-id**.
En Appium (UiAutomator2) se localizan con `By.id("<tag>")` o `AppiumBy.id("<tag>")`, sin prefijo de paquete.

Los ids con `{…}` son dinámicos (por ejemplo `hotel_card_4`, `btn_aceptar_EAPXTQ1F7L`). Para el primero de una lista:
`//*[starts-with(@resource-id,'hotel_card_')]`.
